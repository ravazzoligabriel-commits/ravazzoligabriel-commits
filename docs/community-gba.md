# GitBoy Advanced · A shared GBA adventure

This profile hosts a **shared**, real Game Boy Advance game controlled through GitHub Issues. Everyone plays on the same save, one turn at a time.

## Play · turn timeline

1. **CHOOSE:** Click a button under the GameBoy screen. This opens a prefilled GitHub Issue.
2. **CONFIRM:** Press **Create / Submit new issue**. Opening the form alone does not send your input.
3. **WAIT:** **There is a processing delay after you confirm the Issue**, often about 15–30 seconds and sometimes longer. GitHub Actions executes your command and publishes the new screenshot; there is no owner approval step.
4. **REFRESH:** Return to the profile and reload the page to see the new screen. Other visitors might have played in the meantime.

**The game does not update instantly when you submit.** The wait is caused by GitHub Actions startup, the shared command queue and image caching. There is no artificial 30-second per-player cooldown.

**Arrows:** movement / menus. **A:** confirm. **B:** back. **START:** menu. **SELECT:** registered item. **L/R:** contextual functions or help. You may adjust the prefilled 12-frame hold to 1–120 frames in the Issue title. There is no artificial per-player cooldown. Commands still execute one at a time, so check the latest frame before deciding the next move.

The screenshot is a real emulator frame, not a GIF. The ROM, saved game, backups and engine source are managed **privately**. The public profile serves only the button links, latest frame, command statistics and shared leaderboard.

The game is an experimental technical demonstration, not affiliated with Nintendo, Game Freak or The Pokémon Company. No downloads or copies of the cartridge are provided.
