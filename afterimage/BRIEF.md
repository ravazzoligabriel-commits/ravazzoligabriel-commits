# AFTERIMAGE — multi-agent lab

A one-page interactive web experience framed as a recovered archive from 2049.

## Tone
- strange, elegant, melancholic, slightly uncanny
- not generic cyberpunk; avoid neon overload and hacker clichés
- black/off-white/red palette with rare cyan diagnostics
- editorial typography + terminal details
- CRT/noise only as restrained texture

## Experience
Visitor enters a damaged archive interface and explores fragments of a dead internet:
- recovered photos
- a chat that appears to still be online
- a map to a city that does not exist
- a broken audio player
- a terminal with odd responses
- malformed ads
- 404 memories
- a DO_NOT_OPEN fragment

## Constraints
- static HTML/CSS/JS only
- no external dependencies
- desktop first, still usable on mobile
- smooth and fast
- all agent work must preserve accessibility and reduced-motion support
- prefer atmosphere and interaction over large amounts of text

## Multi-agent experiment
Shiina is lead/integrator. OpenCode/Muse Spark agents act as specialists. Each specialist should inspect this brief and the current files before proposing or changing anything.
